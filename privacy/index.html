YouTube Analytics Automation

最終更新日：2026年11月9日

1. 利用目的

本アプリは、管理者自身の「見るだけスマホ解決室」YouTubeチャンネルの運営状況を分析し、週次レポートを作成するために使用します。

2. アクセスするGoogleユーザーデータ

Google OAuthで承認された範囲内で、YouTubeチャンネルと動画のメタデータ、公開状態、YouTube Analyticsの視聴回数・視聴時間などの分析情報を取得します。読み取り専用の権限を使用します。

3. 保存と利用

取得した情報、生成した分析ファイルおよびOAuth認証情報は、管理者が管理する実行環境内に保存し、週次分析・運用改善のために使用します。分析資料の外部サービスへの取り込みを行う場合は、管理者の判断で必要な資料を選択します。

4. 第三者提供

本アプリは広告配信やデータ販売を目的としません。管理者が明示的に選択して共有する分析資料を除き、アプリが取得データを一般公開することは想定していません。

5. 保管と削除

ローカルで保存されたデータは管理者の管理下に置かれます。不要になったファイルや認証情報は、管理者が削除・失効処理を行います。

6. Google APIの利用

Google APIを通じて得た情報の利用に関して、適用されるGoogle API Services User Data Policyに従います。

7. お問い合わせ

管理者への問い合わせ先は、OAuth同意画面に表示されるユーザーサポートメールをご利用ください。
